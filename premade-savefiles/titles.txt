# The other title ids a game runs under, and the folder whose premade savefiles they take. One per
# line:
#
#   TITLEID[/game]   folder
#
# game is rac1, rac2, rac3 or rac4, for a title id that holds more than one game. A title id with a
# folder of its own needs no line. Only a title qwark runs the same executable under belongs here:
# a save is the game's own save buffer, and another build of the game may lay it out differently.

# RaC2 repacks: NPEA00386 under another title id, byte for byte where it matters. qwark gives them
# NPEA00386's fingerprint and table (src/games/rac2.c).

BLMODYOOO        NPEA00386
